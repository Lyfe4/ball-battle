# Architecture decision records

Why the code is the way it is, one decision per record, numbered in the order they were made.
Records are never deleted or rewritten: a later one amends or supersedes an earlier one, and both
stay, because what was tried and dropped is part of the reason. A new decision takes the next
number; when it changes an earlier one, it says so in its header (`Amends:`), and the earlier
one gains an `Amended by:` line.

**Status** is each record's own header. **Changed by** lists the later records that amend or
supersede it (from both records' headers).
